# Virement Maîtrisé

Ce dépôt contient le module 'Virement Maîtrisé' pour WooCommerce.

## Installation

- Téléchargez le fichier .zip
- Importez le fichier dans WordPress

## Prérequis

### PrestaShop 8

| Prérequis            | Configuration                                      |
|----------------------|----------------------------------------------------|
| Version PHP          | 7.2                                                |
| Version WooCommerce  | 3.9                                                |
| Extensions PHP       | ext-curl, ext-json, ext-mbstring, ext-openssl, ext-intl |
